METAR / TAF Decoder

Paste a raw weather report and see it translated into plain English

How to Use

Paste a raw METAR (current observation) or TAF (forecast) into the textbox below and click Decode. Each token will be color-coded by category and translated into plain English. Use Load Example to cycle through sample reports.

Exam tip: On the Part 107 exam you'll be expected to read METARs and TAFs directly. Use this tool to build familiarity — not as a crutch during testing.
